# World Clock

A small browser app that shows the current time for several time zones and lets you save your selected zones in local storage.

## Features

- Live digital clocks for multiple time zones
- Add or remove zones from the UI
- Remembers your selected time zones using `localStorage`
- Responsive design for desktop and mobile

## Run locally

1. Open `index.html` in a browser.
2. Or serve the folder with a simple static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — main app layout
- `styles.css` — styling and responsive layout
- `script.js` — live clock logic and localStorage handling
